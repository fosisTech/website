# IMAGES

Every image referenced by the crawled pages: `<img>` sources, `srcset` entries, CSS
`background-image` declarations, the `og:image` tags, the site logo, and the favicon family.

Images were downloaded at the **largest resolution available**. The site serves everything
through the WordPress.com Photon CDN (`i0.wp.com`), so the URLs in the HTML carry transform
query strings (`?fit=`, `?resize=`, `?w=`). Dropping the query returns the original upload,
and that is what was saved. Where an image was only ever embedded at a small size, the
original upload itself is that small; the `Stored size` column shows what was actually
retrievable, and `Displayed` shows the largest size the page asks for.

Counts: **131 content image files on disk**, plus 12 files in `images/favicons/`.
